## Detailed description

Lock In blocks distracting websites according to rules you choose. Organize sites into zones, close them during scheduled hours, give them a daily time allowance, or combine both rules.

Main features:

- Block any user-selected HTTP or HTTPS domain.
- Create reusable groups of distracting sites.
- Schedule blocking windows by weekday, including overnight windows.
- Set optional daily allowances measured only while a configured site is the active tab of the focused window.
- Require a manual typing challenge before disabling, deleting, or weakening existing rules.
- See the current state, the next scheduled change, today's timeline, and a local daily blocked-visit tally.
- Keep all settings and usage information on the device. Lock In has no server, analytics, ads, or account system.

Lock In reads the hostname of the active tab only to match it against domains you configured and measure an enabled daily allowance. It does not read page content. All configuration and usage totals remain in Chrome local storage and are never transmitted or shared.

## Single purpose

Lock In's single purpose is to help users avoid distracting websites by blocking user-selected domains according to schedules and daily allowances, with deliberate friction before existing restrictions can be weakened.
